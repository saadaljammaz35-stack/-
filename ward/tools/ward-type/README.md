# WARD TYPE — Original 0.1

مصدر رسم خط هندسي تجريبي من الصفر لمشروع وارد. لا يقرأ البرنامج أو يستورد أي ملف خط خارجي، ولا يعتمد على أشكال Noto أو غيرها. جميع المسارات والإحداثيات موجودة في build.py. مكتبات Python تستخدم فقط لتكوين المنحنيات ومخرجات OpenType.

## التشغيل

```sh
python -m pip install -r requirements.txt
python build.py --out dist
```

ينتج البناء خمسة أوزان ثابتة (300، 400، 500، 700، 900) بصيغ TTF وWOFF2 محليًا. لا تتضمن هذه الحزمة ملفات الخط المبنية. مثال للاستخدام في الموقع:

```css
@font-face {
  font-family: 'WARD Type Original';
  src: url('/fonts/WARDTypeOriginal-Regular.woff2') format('woff2');
  font-weight: 400;
  font-display: swap;
}
```

كرر التعريف للأوزان Light وMedium وBold وBlack مع القيم المناسبة. لا تستبدل خط الموقع في الإنتاج قبل اختبار واجهاته.

## نطاق النسخة

153 محرف Unicode و258 glyph لكل وزن؛ العربية الأساسية وأشكال الوصل، الحروف الإنجليزية الكبيرة والصغيرة، الأرقام العربية والغربية، التشكيل الأساسي وعلامات الترقيم المحددة في المصدر. يدعم GSUB (init/medi/fina/rlig) وGPOS (mark) بشكل أولي. اختبر البناء بصيغتي TTF وWOFF2 وعرض عبارات عربية بمحرك RAQM. هذا نموذج أولي وليس خطًا إنتاجيًا نهائيًا؛ يحتاج اختبارًا لغويًا وبصريًا أوسع، ضبط المسافات، تحسين بعض أشكال الوصل، التشكيل المركب، ودعمًا أوسع للمحارف. لا يوجد إصدار OTF/CFF أو variable font في هذا الإصدار. لا توجد شهادة قانونية بعدم تشابه الخط مع تصاميم أخرى، ولا إثبات تسجيل ملكية حصرية.
