# أوامر يوتيوب (/yt-*)

11 أمر لإدارة قناة يوتيوب، موجودة في `.claude/skills/yt-*` وتشتغل في أي جلسة Claude Code على هذا
المشروع، بما فيها جلسات السحابة.

| الأمر | وش يسوي |
| --- | --- |
| `/yt-script` | يكتب سكربت الفيديو من فكرة، ويعطيك أكثر من افتتاحية (هوك) مع درجة لكل وحدة |
| `/yt-package` | يقترح العنوان ونص الصورة المصغّرة، ويفحصهم مع بعض قبل النشر |
| `/yt-seo` | يكتب الوصف والتاقات عشان الناس يلقون الفيديو في البحث |
| `/yt-shorts` | يطلع لك مقاطع Shorts من الفيديو الطويل |
| `/yt-edit` | يحدد لك وش تقص من التسجيل: السكتات والإعادات |
| `/yt-chapters` | يقسّم الفيديو لفصول (chapters) |
| `/yt-retention` | يحدد بالضبط وين يطلع المشاهدين من الفيديو |
| `/yt-comment` | يكتب ردود على التعليقات بأسلوبك |
| `/yt-plan` | يخطط لك جدول النشر الأسبوعي أو الشهري |
| `/yt-audit` | يراجع قناتك كاملة |
| `/yt-viral` | يدور على الفيديوهات اللي جابت مشاهدات أكثر بكثير من معدل قنواتها في مجالك |

## ملف أسلوبك: `voice.md`

كل الأوامر تقرأ `.claude/youtube/voice.md`. انسخ `voice.example.md` إلى `voice.md` وعبّه، أو أرسل
لـ Claude ثلاث فيديوهات من قناتك وقل له «اكتب voice.md من هذي».

## المصدر والتعديلات

الأصل: [Jakeschincariol/youtube-agent-skill](https://github.com/Jakeschincariol/youtube-agent-skill)
(نسخة `a2feb21`، رخصة MIT، انظر `LICENSE-youtube-agent-skill`).

التعديلات هنا:

- **دعم العربي** في الأدوات الست: `yt-script/arabic.py` (توحيد الإملاء، حذف التشكيل و«ال»، قوائم
  كلمات فصحى وسعودية)، وأنماط عربية `match_ar` للصيغ الـ21 في `yt-script/hooks.json`.
- **`yt-edit/transcribe.py`**: يفرّغ الفيديو أو الصوت إلى `srt` و`json` بـ faster-whisper (عربي
  افتراضيًا)، ويقطّع النص عند السكتات الحقيقية.
- **`voice.md` داخل المشروع** بدل `~/.claude/youtube/` عشان ما يضيع بين جلسات السحابة.
