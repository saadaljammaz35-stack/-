# لَبِنة · استوديو الطفولة

موقع متكامل لاستوديو متخصص في عالم الأطفال: تصوير المواليد والأطفال والعائلات وأعياد الميلاد والمناسبات، وتصوير منتجات الأطفال، وتصميم الألبومات، والتجارب الإبداعية للصغار. يضم الموقع العام بالعربية (RTL)، ونظام حجز حقيقياً متصلاً بقاعدة البيانات، ولوحة تحكم محمية بصلاحيات.

**التقنيات:** Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Framer Motion · Supabase (قاعدة البيانات، المصادقة، التخزين) · Zod

## ما الذي يتضمنه المشروع

### الموقع العام
| الصفحة | المسار |
|---|---|
| الرئيسية: الواجهة، الخدمات، خطوات الجلسة، المعرض، من نحن، آراء العملاء، الحجز، الأسئلة | `/` |
| الخدمات وتفاصيل كل خدمة | `/services` · `/services/[slug]` |
| معرض الصور (Masonry + تصنيفات + عرض مكبّر بالسحب ولوحة المفاتيح) | `/gallery` |
| من نحن (القصة، الرسالة، الرؤية، القيم) | `/about` |
| الأسئلة الشائعة (مع بيانات منظمة لمحركات البحث) | `/faq` |
| تواصل معنا (نموذج حقيقي يصل إلى لوحة التحكم) | `/contact` |
| الحجز بثلاث خطوات | `/booking` |
| إدارة الحجز للعميل عبر رابط سري (عرض الحالة والإلغاء) | `/booking/manage/[token]` |

### نظام الحجز
- يعرض **الأوقات المتاحة فقط** حسب ساعات العمل، ومدة كل جلسة، والحجوزات الحالية، وأيام الإغلاق، والمهلة الدنيا.
- **منع الحجز المزدوج على مستوى قاعدة البيانات** بقيد `EXCLUDE` على نطاقات الوقت؛ لا يمكن أن يتداخل حجزان نشطان حتى لو أُرسلا في اللحظة نفسها (مُختبر بـ 8 طلبات متزامنة: نجح واحد فقط).
- التحقق من البيانات مرتين: في الخادم (Zod) وداخل دالة قاعدة البيانات نفسها.
- رقم حجز مثل `LB-7HW9TM`، ورابط خاص للعميل لمتابعة الحجز أو إلغائه قبل المهلة المحددة.
- إضافة الموعد إلى التقويم (ملف `.ics`)، وتحويل الأرقام العربية (٠٥٠…) تلقائياً.
- سجل كامل لكل حجز: الإنشاء، تغيّر الحالة، تعديل الموعد، الإلغاء، ومن قام به ومتى.
- رسائل بريد تلقائية للعميل وللاستوديو **عند تفعيل خدمة البريد** (Resend). بدونها يعمل النظام كاملاً.

## التشغيل محلياً

المتطلبات: Node.js 20.9 أو أحدث، وDocker (لتشغيل Supabase محلياً).

```bash
cd labina-studio
npm install

# 1) تشغيل Supabase محلياً وتطبيق الجداول والبيانات الافتراضية
npx supabase start
npx supabase db reset

# 2) إعداد متغيرات البيئة
cp .env.example .env.local
#   انسخ API URL و anon key و service_role key من مخرجات `npx supabase status`

# 3) إنشاء حساب المسؤول
npm run admin:create -- you@example.com "كلمة-مرور-قوية" "اسمك"

# 4) التشغيل
npm run dev        # http://localhost:3000  ولوحة التحكم على /admin
```

بدون ربط Supabase يعمل الموقع في **وضع المعاينة**: يظهر التصميم والخدمات، ويوضّح نموذج الحجز بصراحة أنه غير متصل بعد بدلاً من التظاهر بأنه يعمل.

أوامر مفيدة:

```bash
npm run check      # فحص الأنواع + ESLint + بناء الإنتاج
npm run admin:create -- staff@example.com "كلمة-مرور" "الاسم" staff   # حساب موظف
```

## ربط Supabase السحابي

1. أنشئ مشروعاً جديداً في [supabase.com](https://supabase.com).
2. طبّق الجداول والسياسات (من مجلد `labina-studio`):
   ```bash
   npx supabase login
   npx supabase link --project-ref YOUR-PROJECT-REF
   npx supabase db push
   ```
   أو انسخ ملفات `supabase/migrations/*.sql` بالترتيب إلى SQL Editor ونفّذها.
3. من **Project Settings → API** انسخ `Project URL` و`anon/publishable key` و`service_role key`.
4. أنشئ المسؤول: ضع القيم في `.env.local` ثم `npm run admin:create -- ...`
   (أو أنشئ المستخدم من Authentication → Users ثم نفّذ:
   `insert into public.admins (user_id, role) select id, 'admin' from auth.users where email = 'you@example.com';`)
5. في **Authentication → URL Configuration** اجعل Site URL هو رابط موقعك.

## النشر على Vercel

1. استورد المستودع في Vercel، واجعل **Root Directory** = `labina-studio`.
2. أضف متغيرات البيئة:

| المتغير | مطلوب | ملاحظة |
|---|:-:|---|
| `NEXT_PUBLIC_SITE_URL` | ✓ | رابط الموقع النهائي، مثل `https://labina.sa` |
| `NEXT_PUBLIC_SUPABASE_URL` | ✓ | |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | ✓ | المفتاح العام فقط |
| `RESEND_API_KEY` | | لتفعيل رسائل البريد |
| `NOTIFY_FROM_EMAIL` | | مثل `لَبِنة <bookings@your-domain.com>` بنطاق موثّق في Resend |
| `STUDIO_NOTIFY_EMAIL` | | بريد تنبيهات الحجوزات (افتراضياً: بريد التواصل من لوحة التحكم) |

> لا تضع `SUPABASE_SERVICE_ROLE_KEY` في Vercel؛ الموقع لا يحتاجه. يُستخدم فقط في سكربت إنشاء المسؤول على جهازك.

3. انشر. الصفحات العامة ثابتة وسريعة، وتتحدث فوراً عند أي تعديل من لوحة التحكم.

## الأمان

- **RLS على كل الجداول.** الزائر يقرأ المحتوى العام فقط؛ الحجوزات والعملاء والرسائل محجوبة عنه تماماً.
- كل عمليات الكتابة العامة (الحجز، الإلغاء، التواصل) تمر عبر دوال `SECURITY DEFINER` تتحقق من كل حقل، مع حدود لمنع الإساءة (3 حجوزات قادمة لكل رقم، و3 رسائل في الساعة لكل مرسل).
- الأدوار: `admin` و`staff`، وتُفحص في كل Server Action وفي قاعدة البيانات. الموظف لا يستطيع تغيير حالة الحجز إلا عبر الدالة المسجَّلة في السجل، ولا يستطيع ترقية نفسه.
- رفع الصور: للمسؤولين فقط، صور فقط (JPEG/PNG/WebP/AVIF)، حتى 10MB، وداخل مجلدات محددة.
- مفاتيح الخدمة والبريد لا تصل إلى المتصفح. رؤوس أمان (HSTS، X-Frame-Options، …) ولوحة التحكم `noindex`.
- حقل مصيدة (honeypot) في النماذج العامة.

## قبل الإطلاق

ستجد هذه الخطوات أيضاً في الصفحة الأولى من لوحة التحكم:

- [ ] بيانات التواصل والعنوان وحسابات التواصل الاجتماعي.
- [ ] أسعار الخدمات ومددها (فارغة عمداً، وتظهر «السعر عند الاستفسار» حتى تُحدَّد).
- [ ] مراجعة ساعات العمل الافتراضية (السبت–الخميس 10:00–20:00، الجمعة مغلق) وإعدادات الحجز.
- [ ] رفع صور المعرض وصور الواجهة **بعد أخذ موافقة الأهل على النشر**.
- [ ] إضافة آراء عملاء حقيقية فقط (القسم مخفي حتى تُضاف أول مراجعة).
- [ ] تفعيل البريد (اختياري) وصفحة سياسة الخصوصية المناسبة لنشاطكم.

## بنية المشروع

```
labina-studio/
├─ supabase/migrations/      الجداول، دوال الحجز، RLS والتخزين، البيانات الافتراضية
├─ scripts/create-admin.mjs  إنشاء حساب مسؤول/موظف
└─ src/
   ├─ app/(site)/            صفحات الموقع العام
   ├─ app/admin/             تسجيل الدخول ولوحة التحكم و Server Actions
   ├─ app/actions/public.ts  الحجز، الإلغاء، التواصل
   ├─ app/api/availability/  الأوقات المتاحة
   ├─ components/            brand · site · booking · admin · ui
   ├─ lib/                   Supabase، الإعدادات، التحقق، التنسيق، البريد
   └─ proxy.ts               حماية مسارات /admin وتحديث الجلسة
```

الهوية البصرية مأخوذة من الشعار: خلفية كريمية `#F5EEDC`، ومرجاني `#DE7968`، وأصفر `#EFC95E`، وبنفسجي `#49285D`، ولافندر `#929FCC`، وتركوازي `#419797`. والمستطيلات المستديرة في الشعار هي «لَبِنات» تتكرر في الواجهة وإطارات الصور وحالات التحميل.
