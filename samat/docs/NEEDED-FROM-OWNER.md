# المطلوب منك للتفعيل الكامل

لا ترسل أي كلمة مرور أو مفتاح في المحادثة. تُضاف المفاتيح في إعدادات Vercel/Supabase مباشرة، أو أطلبها منك عبر نموذج آمن.

## ضروري للنشر
1. ~~بريد المالك~~ ✅ (بريدان، مضافان في Vercel فقط).
2. ~~الموافقة على إنشاء المشاريع~~ ✅ (Supabase «samat» في فرانكفورت + Vercel «samat»).
3. **مفتاح الخادم (`SUPABASE_SERVICE_ROLE_KEY`) في Vercel**: الخطوة الوحيدة الباقية للنشر.
   - انسخه من حساب Supabase المالك لمشروع «samat» (منظمة «دوري»): Project Settings ← API Keys ← service_role.
   - أضفه في Vercel ← samat ← Settings ← Environment Variables (Production + Preview، Sensitive)، ثم تُنشر نسخة جديدة.
4. **دخول الإدارة بكلمة مرور** (لا يحتاج إعدادات البريد في Supabase): كل مالك يختار كلمته أول مرة من **رابط إعداد لمرة وحدة** صالح ٧٢ ساعة. والمالك يصنع روابط الموظفين من صفحة «الموظفون» ويرسلها لهم بواتساب. الدخول برمز البريد اختياري لاحقاً مع مزوّد بريد.
5. **النطاق** (الدومين): اكتب اسمه، وأضيفه في Vercel وأعطيك سجلات DNS تضيفها عند مزوّد الدومين.

## ضروري قبل البيع الفعلي
6. **أسعار المنتجات** والمكونات الإضافية والصوصات، من `/admin/menu`. المنتجات الثلاثة في الموقع المنشور مسودات بدون أسعار، ولا تظهر للعملاء حتى تسعّرها وتنشرها.
7. **بيانات الفرع:** الاسم، العنوان، رابط الخريطة، رقم الهاتف، أوقات العمل.
8. **بيانات الفاتورة:** الاسم القانوني، الرقم الضريبي، السجل التجاري، والأسعار شاملة الضريبة أو لا.
9. **المخزون الافتتاحي** وحدود التنبيه.

## لتفعيل الخدمات (اختياري حسب رغبتك)
| الخدمة | المطلوب |
|---|---|
| ميسّر (بطاقات / مدى / Apple Pay) | حساب تاجر + مفاتيح test ثم live + تسجيل الدومين لـ Apple Pay |
| البريد | حساب Resend + توثيق الدومين (أو SMTP) |
| دخول العملاء بحساب Google | Client ID من Google Cloud (مجاني، بدون وثائق). يُضاف في Vercel باسم `NEXT_PUBLIC_GOOGLE_CLIENT_ID` |
| دخول العملاء برسالة | ✅ مربوط بـ Twilio Verify (خدمة SAMAT، والقيم في Vercel). **باقي:** الحساب تجريبي، فيرسل فقط للأرقام الموثّقة في Twilio. للإرسال لكل العملاء: Upgrade + ملف امتثال (Compliance Profile). وتأكد أن السعودية «Allow» في Verify ← Geo Permissions |
| واتساب | WhatsApp Business Cloud API + قوالب معتمدة (أسماؤها في NOTIFICATIONS.md) |
| SAMAT AI | مفتاح Anthropic API |
| الطابعة | موديل الطابعة عند الشراء (USB / بلوتوث / شبكة) |
