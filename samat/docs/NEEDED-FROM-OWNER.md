# المطلوب منك للتفعيل الكامل

لا ترسل أي كلمة مرور أو مفتاح في المحادثة. تُضاف المفاتيح في إعدادات Vercel/Supabase مباشرة، أو أطلبها منك عبر نموذج آمن.

## ضروري للنشر
1. **بريد المالك** (`SUPER_ADMIN_EMAIL`): البريد الذي سيدير المطعم.
2. **موافقتك على إنشاء:**
   - مشروع Supabase جديد في منظمتك (الخطة المجانية تسمح بمشروعين نشطين، وعندك مشروعان حالياً).
   - مشروع Vercel في فريق «sahm».
3. **النطاق** (الدومين) إن وُجد، مثل `samat.sa`.

## ضروري قبل البيع الفعلي
4. **أسعار المنتجات النهائية** والمكونات الإضافية والصوصات. لم أضع أسعاراً نهائية؛ الموجود تجريبي.
5. **بيانات الفرع:** الاسم، العنوان، رابط الخريطة، رقم الهاتف، أوقات العمل.
6. **بيانات الفاتورة:** الاسم القانوني، الرقم الضريبي، السجل التجاري، والأسعار شاملة الضريبة أو لا.
7. **المخزون الافتتاحي** وحدود التنبيه.

## لتفعيل الخدمات (اختياري حسب رغبتك)
| الخدمة | المطلوب |
|---|---|
| ميسّر (بطاقات / مدى / Apple Pay) | حساب تاجر + مفاتيح test ثم live + تسجيل الدومين لـ Apple Pay |
| البريد | حساب Resend + توثيق الدومين (أو SMTP) |
| SMS | حساب Unifonic أو Taqnyat + اسم مرسل معتمد |
| واتساب | WhatsApp Business Cloud API + قوالب معتمدة (أسماؤها في NOTIFICATIONS.md) |
| SAMAT AI | مفتاح Anthropic API |
| الطابعة | موديل الطابعة عند الشراء (USB / بلوتوث / شبكة) |
