# الإشعارات — SAMAT

كل إشعار يُسجَّل في جدول `notifications` بمفتاح فريد (`طلب:حدث:قناة`)، فلا يُرسل نفس الإشعار مرتين حتى لو وصل الـ Webhook أكثر من مرة. الحالة لكل سجل: **أُرسل / فشل / بانتظار الإرسال / غير مفعّل**، وتظهر في لوحة الإدارة ← سجل الإشعارات. الرسائل الفاشلة يُعاد إرسالها (حتى ٣ محاولات خلال ٢٤ ساعة) عبر `/api/cron`.

## رسائل العميل

| الحدث | النص العربي |
|---|---|
| استلام الطلب | وصلنا طلبك يا هلا! ننتظر تأكيد المطعم. |
| القبول | تم قبول طلبك، وبدأنا نجهزه. |
| بدء التحضير | طلبك تحت التجهيز، بالعافية عليك مقدماً. |
| الجاهزية | طلبك جاهز يا هلا، تفضل استلمه من الفرع. |
| الرفض | نعتذر منك، ما قدرنا نقبل طلبك. راجع تفاصيل الطلب لمعرفة السبب. |
| الاسترجاع | تم استرجاع مبلغ طلبك عبر بوابة الدفع… |

اللغة حسب لغة العميل وقت الطلب (عربي/إنجليزي).

## رسائل الإدارة (بريد)

- **طلب جديد:** فيه رقم الطلب، رقم الفاتورة إن وجد، اسم العميل وجواله، المنتجات بكل مكوناتها والصوصات والإضافات، الإجمالي، حالة الدفع، ووقت الطلب.
- **تنبيهات:** مخزون منخفض، مشكلة في الدفع (فشل التحصيل/الاسترجاع، أو استرجاع تحويل يدوي مطلوب).
- العناوين تُحدد من **الإعدادات ← إيميلات الإدارة**؛ وإذا كانت فارغة يُستخدم `SUPER_ADMIN_EMAIL`.

## القنوات

### البريد (Resend أو SMTP)
- Resend: `EMAIL_PROVIDER=resend`، `RESEND_API_KEY`، و`EMAIL_FROM` من دومين موثّق في Resend.
- SMTP: `EMAIL_PROVIDER=smtp` + `SMTP_HOST/PORT/USER/PASS`.

### SMS
- `SMS_PROVIDER=unifonic` + `UNIFONIC_APP_SID`، أو `taqnyat` + `TAQNYAT_BEARER_TOKEN`، أو `twilio` + مفاتيحه.
- `SMS_SENDER_NAME` لازم يكون اسم مرسل معتمد لدى المزود (هيئة الاتصالات تشترط تسجيل اسم المرسل).
- نفس المزود يرسل **رموز دخول العملاء**. الموقع يرسل الرمز بنفسه (`/api/auth/phone/*`)، فلا تحتاج إعدادات الجوال في Supabase. يُحفظ في قاعدة البيانات بصمة الرمز فقط، وصلاحيته ٥ دقائق و٥ محاولات، وإعادة الإرسال بعد دقيقة وبحد ٥ مرات في الساعة.
- بدون مزود رسائل تظهر للعميل رسالة «الدخول برقم الجوال يتفعّل قريباً»، ويقدر يطلب كضيف.

### واتساب (WhatsApp Business Cloud API)
- `WHATSAPP_ENABLED=true` + `WHATSAPP_PHONE_NUMBER_ID` + `WHATSAPP_ACCESS_TOKEN`.
- واتساب يتطلب **قوالب معتمدة من Meta** للرسائل خارج نافذة ٢٤ ساعة. أنشئ هذه القوالب (عربي `ar` وإنجليزي `en`)، وكل قالب يأخذ رقم الطلب كمتغير `{{1}}`:
  `samat_order_received`، `samat_order_accepted`، `samat_order_preparing`، `samat_order_ready`، `samat_order_rejected`، و`samat_otp` (قالب Authentication لرمز الدخول).

> بدون مفاتيح لا يدّعي النظام أي إرسال: تُسجَّل الرسالة بحالة **غير مفعّل** ولا شيء غير ذلك.
