# ضَمان · Damaan

**خزنة فواتيرك وضماناتك.** تطبيق iOS يحفظ فواتير مشترياتك، ويحسب لك ثلاث مهل تبدأ من
يوم الشراء — **الاستبدال، الاسترجاع، الضمان** — وينبّهك قبل أن تنتهي، ثم يجهّز لك
خطاب مطالبة رسميًا بصورة الفاتورة، جاهزًا للإرسال للمتجر.

يعمل بالكامل على جهازك: **بدون حساب، بدون سيرفر، بدون تتبّع، وبدون إنترنت.**

---

## المشكلة

تشتري جوالًا بـ ٤٠٠٠ ريال. يتعطّل بعد أحد عشر شهرًا والضمان سنة — وين الفاتورة؟
ضاعت. أو تكتشف بعد ثلاثة أسابيع أن المنتج ما يناسبك، ومهلة الاسترجاع كانت أسبوعين.

الحل الحالي عند معظم الناس هو تصوير الفاتورة وتركها بين ثمانية آلاف صورة في الاستديو.
هذا ليس أرشيفًا — هذا فقدان مؤجّل.

## ما يفعله التطبيق

| | |
|---|---|
| **يحفظ** | صورة الفاتورة في مكان لا يحذفه النظام، مع المتجر والمبلغ وتاريخ الشراء |
| **يحسب** | ثلاث مهل من تاريخ الشراء، مع شريط تقدّم لكل واحدة وعدّاد بالأيام |
| **ينبّه** | قبل ٣ أيام ويوم من نهاية الاسترجاع، ويوم من الاستبدال، وشهر وأسبوع من نهاية الضمان |
| **يطالب** | خطاب PDF رسمي بالعربي فيه بياناتك ووصف المشكلة وصورة الفاتورة — أو رسالة نصية جاهزة للواتساب |
| **يحمي** | قفل Face ID اختياري، ونسخة احتياطية في ملف واحد تحتوي الفواتير وصورها |

## التقنية

| | |
|---|---|
| الإطار | Expo SDK 57 · React Native 0.86 · React 19 |
| اللغة | TypeScript في الوضع الصارم (`strict`, `noUncheckedIndexedAccess`) |
| التنقّل | **Expo Router** فوق native-stack — مسارات بالملفات، ويستخدم `UINavigationController` الأصلي، فتحصل على Large Titles وترويسة ضبابية وإيماءة رجوع حقيقية |
| قاعدة البيانات | `expo-sqlite` مع ترقيات مُرقَّمة عبر `user_version` |
| الصور | `expo-file-system` — في مجلد المستندات، لا الكاش، حتى لا يحذفها النظام |
| التنبيهات | `expo-notifications` محلية بالكامل |
| الأيقونات | `expo-symbols` — رموز SF Symbols الأصلية من آبل |
| التصميم | نظام رموز مبني على Human Interface Guidelines (انظر `src/theme/tokens.ts`) |

### التصميم

لا يوجد لون واحد مكتوب داخل أي مكوّن. كل الألوان تأتي من لوحة دلالية في
`src/theme/tokens.ts` تعيد نفسها للوضع الفاتح والداكن، بنفس أسماء آبل
(`secondaryGroupedBackground`، `separator`، `tertiaryLabel`…). المقاسات على إيقاع
٨ نقاط، والأنماط النصية هي أنماط iOS نفسها (`largeTitle` 34/41، `body` 17/22…).
حجم أصغر هدف لمس هو ٤٤ نقطة كما تنص الإرشادات.

الخط متروك لنظام التشغيل، فتحصل تلقائيًا على **SF Arabic** على iOS. التطبيق عربي
بالكامل واتجاهه من اليمين لليسار عبر `I18nManager.forceRTL` قبل أول رسم.

### بنية المجلدات

```
src/
  app/          المسارات (Expo Router) — ملفات رفيعة تربط المسار بالشاشة
    _layout.tsx     المزوّدات + المكدّس + فتح الفاتورة عند الضغط على تنبيه
    index.tsx       /                  الرئيسية
    settings.tsx    /settings          الإعدادات
    receipt/
      [id].tsx      /receipt/:id       تفاصيل الفاتورة
      form.tsx      /receipt/form      إضافة أو تعديل (يُعرض كـ modal)
      claim.tsx     /receipt/claim     المطالبة
  theme/        لوحة الألوان والأنماط والمقاسات — لا ألوان خارج هذا المجلد
  ui/           بدائيات الواجهة: قوائم مجمّعة، أزرار، شرائح، حقول، شرائط تقدّم
  domain/       المنطق الخالص: التواريخ، المهل، الفئات، المبالغ  ← مُغطّى باختبارات
  db/           SQLite: الاتصال، الترقيات، مستودع الفواتير
  services/     الصور، التنبيهات، محلّل الفاتورة، خطاب المطالبة، النسخ الاحتياطي، القفل
  state/        مزوّد حالة الفواتير
  features/     الشاشات نفسها: home · add · detail · claim · settings
  navigation/   أنواع معاملات المسارات ومحوِّلاتها
tools/
  make-icons.py   يولّد كل الأيقونات من مصدر متجهي واحد
```

قاعدتان شكّلتا البنية:

1. **`domain/` لا يعرف شيئًا عن React ولا SQLite ولا Expo** — لذلك يُختبَر على Node
   مباشرة، وهو ما يحدث فعلًا.
2. **`src/app/` يحتوي المسارات فقط** — الشاشات نفسها في `features/`، تمامًا كما ينص
   `AGENTS.md`.

### التحقق قبل أي رفع

```bash
npm run verify     # typecheck + lint + 42 اختبارًا
```

الاختبارات تعمل على Node مباشرة عبر `tsx`، بدون مُحاكي وبدون Jest:

```bash
npm test
```

وهي تغطّي ما يجب أن يكون صحيحًا مهما حدث:

- **حساب المهل** — إضافة الشهور مع تثبيت اليوم داخل الشهر (٣١ يناير + شهر = ٢٨ فبراير)، والتدرّج من `active` إلى `soon` إلى `critical` إلى `expired`، وأن شريط التقدّم لا يخرج أبدًا عن ٠…١
- **الصياغة العربية** — المفرد والمثنى وجمع القلة وجمع الكثرة (`يوم واحد` · `يومين` · `5 أيام` · `20 يومًا`)
- **المبالغ** — تُخزَّن بالهللات كأعداد صحيحة، فلا يوجد عدد عشري عائم في أي مكان
- **قراءة الفاتورة** — ٢٣ اختبارًا على المحلّل، بفاتورة سعودية حقيقية الشكل

## تشغيل قراءة الفاتورة تلقائيًا

محلّل الفاتورة في `src/services/parseReceipt.ts` **جاهز ومُختبَر بالكامل**: يستخرج
المتجر والمبلغ وتاريخ الشراء والرقم الضريبي من نص الفاتورة، ويتعامل مع الأرقام
العربية والهندية، ومع `الإجمالي شامل الضريبة` دون أن يخطئ ويأخذ سطر الضريبة أو
المدفوع أو الباقي، ويرفض التواريخ المستقبلية والمستحيلة.

ما يحتاجه هو **النص الخام**، والحصول عليه من صورة يتطلّب وحدة تعرّف ضوئي أصلية،
ولا يشحن Expo واحدة. لذلك التعرّف **قابل للتوصيل**: تُسجّل مُنفِّذًا عند الإقلاع
ويبدأ العمل فورًا. وإلى أن تفعل، تظل شاشة الإضافة نموذجًا سريعًا — وهو منتج كامل
بحد ذاته.

في `src/app/_layout.tsx`:

```ts
import { registerTextRecognizer } from '../services/ocr';

registerTextRecognizer(async (uri) => {
  // أعِد نص الفاتورة كسلسلة واحدة، بأسطر مفصولة بـ \n
});
```

أمامك طريقان:

**١. وحدة أصلية على الجهاز** (مجاني، أوفلاين، خاص) — أضف حزمة تعرّف نصوص أصلية
وابنِ التطبيق ببناء أصلي (`eas build`، لا Expo Go). انتبه: معظم الوحدات المتاحة
تقرأ الحروف اللاتينية بدقة عالية والعربية بدقة أقل — وهذا يكفي في الغالب، لأن
المبالغ والتواريخ على الفواتير السعودية تُطبع بأرقام لاتينية.

**٢. نقطة نهاية تملكها** — أرسل الصورة لخدمة تعرّف وأعِد النص. أسهل وأدق، لكنها
تعني أن صورة الفاتورة تخرج من الجهاز، ويجب أن تذكر ذلك في سياسة الخصوصية وفي
نموذج App Privacy.

في الحالتين، يعرض التطبيق للمستخدم ما قرأه ويطلب منه المراجعة قبل الحفظ — لا يُحفظ
شيء قرأته الآلة بدون موافقة بشرية.

## ملاحظة مهمة عن مهل الاسترجاع والاستبدال

القيم الافتراضية في التطبيق — **١٤ يومًا للاسترجاع و٧ أيام للاستبدال** — هي أرقام
شائعة في السوق السعودي، **وليست نصًا نظاميًا**. سياسة الاستبدال والاسترجاع تختلف من
متجر لآخر، والمتجر ملزم بإعلان سياسته.

لذلك بُنِي التطبيق على أن هذه القيم **قابلة للتعديل** لكل فاتورة على حدة ومن
الإعدادات، والنص الظاهر للمستخدم يقول ذلك صراحة. وخطاب المطالبة **لا يستشهد برقم
مادة نظامية** — يعرض الواقعة ويطلب الحق، دون ادّعاء قانوني قد يكون خاطئًا.

**قبل النشر:** راجع سياسة وزارة التجارة الحالية وعدّل القيم الافتراضية والنصوص إن
لزم. لا تنشر أرقامًا نظامية لم تتحقّق منها بنفسك.
