# مع الله

تطبيق إسلامي يومي للقرآن والصلاة والذكر على iOS وAndroid (ويعمل أيضًا في المتصفح بقدرات أقل)، مبني بـ Expo / React Native. كل نص شرعي فيه منقول من مصدر موثق ومذكور داخل التطبيق في «المصادر والتوثيق»؛ لا يُكتب أي نص يدويًا ولا يُولَّد بالذكاء الاصطناعي.

## المحتوى ومصادره

| المحتوى | المصدر | ملاحظات |
| --- | --- | --- |
| نص القرآن (٦٢٣٦ آية، ٦٠٤ صفحات) | Quran.com API — خط مجمع الملك فهد (حفص) | يُقابَل آليًا بنص tanzil.net، ويتطابق كاملًا |
| التفسير الميسر والسعدي | Quran.com API | مضمّنان دون إنترنت؛ ابن كثير والطبري والقرطبي والبغوي والوسيط عند الطلب |
| أسباب النزول (١٨٩ رواية في ٥٥ سورة) | «الصحيح المسند من أسباب النزول» للوادعي (turath.io) | تُربط كل رواية بآياتها بمطابقة نص الآية المقتبس |
| حصن المسلم (٢٦٧ ذكرًا مع التخريج والصوت) | turath.io (طبعة سفير) وhisnmuslim.com | |
| أذكار الصباح والمساء | Seen-Arabic/Morning-And-Evening-Adhkar-DB | مع العدد والفضل والمصدر |
| موسوعة الأحاديث (٣٥٧٤ حديثًا) | HadeethEnc.com | مع الدرجة والشرح |
| الكتب السبعة: البخاري، مسلم، أبو داود، الترمذي، النسائي، ابن ماجه، الموطأ | fawazahmed0/hadith-api (إصدار مثبّت) | تُحمَّل عند الطلب ويُتحقق منها بـ SHA-256 وبأحاديث مرجعية؛ الأربعون النووية والقدسية مضمّنة |
| أسماء الله الحسنى | الترمذي ٣٥٠٧ + شرح الخطابي «شأن الدعاء» | يذكر التطبيق أن سرد الأسماء في الحديث ضعيف |
| المدن | GeoNames (CC BY 4.0) | |
| صوت الأذان | تسجيل زوّد به صاحب التطبيق (`scripts/data/make-adhan.mjs`) — يلزم إذن صاحب الحقوق قبل النشر في المتاجر | أندرويد: الأذان كاملًا · iOS: أول ٢٤ ثانية (حدّ ٣٠ ثانية) |

مسند الإمام أحمد غير مضمّن لعدم توفر نسخة رقمية كاملة موثقة مفتوحة الترخيص.

## التشغيل

يتطلب Node 22.5 أو أحدث (لبناء قاعدة البيانات بـ `node:sqlite`).

```bash
npm install          # يبني assets/db/content.db تلقائيًا من مجلد data/
npx expo start       # ثم شغّل على جهاز بتطبيق تطوير (development build)
```

التطبيق يحتاج **Development Build** وليس Expo Go، لأنه يستخدم وحدات أصلية (الودجت، الأيقونات البديلة، الإشعارات).

### الأوامر

| الأمر | الوظيفة |
| --- | --- |
| `npm test` | اختبارات الوحدة (المواقيت، التقويم، الختمة، جدولة الإشعارات، صحة الروابط) |
| `npm run typecheck` / `npm run lint` | فحص الأنواع والكود |
| `npm run data:build` | بناء قاعدة المحتوى من `data/` |
| `npm run data:verify` | فحوص سلامة المحتوى (عدد الآيات، الصفحات، الأذكار، كتب الحديث…) |
| `npm run data:fetch` | إعادة جلب كل المصادر من الإنترنت والتحقق منها ثم البناء |

## البنية

- `src/app` — الشاشات (Expo Router)، والتبويبات: الرئيسية، القرآن، الأذكار، القبلة، المزيد.
- `src/lib` — منطق صافٍ ومختبَر: المواقيت (adhan)، التقويم الهجري (أم القرى)، الختمة، رمضان، القبلة، جدولة الإشعارات.
- `src/data` — قاعدة المحتوى (SQLite مضمّنة) والمصادر عبر الإنترنت مع تخزين مؤقت.
- `src/features` — الصوت، الإشعارات، الودجت، كتب الحديث، النسخ الاحتياطي، المزامنة.
- `src/widgets` — ودجت iOS (SwiftUI) وAndroid (Compose) عبر `expo-widgets`.
- `scripts/data` — خط جلب المحتوى والتحقق منه وبناء قاعدة البيانات.
- `supabase/migrations` — جدول المزامنة الاختيارية مع سياسات RLS ودالة حذف الحساب.

## النشر على المتاجر

1. أنشئ حسابًا في [expo.dev](https://expo.dev) ثم: `npx eas-cli@latest login` و`npx eas-cli@latest init`.
2. عدّل في `app.json` عند الحاجة: `ios.bundleIdentifier` و`android.package` (حاليًا `com.maallah.app`)، و`expo.extra` (بريد الدعم، روابط المتجر).
3. البناء: `npx eas-cli@latest build --platform all --profile production` (يبني EAS قاعدة المحتوى تلقائيًا عبر `eas-build-post-install`).
4. الرفع: `npx eas-cli@latest submit --platform ios` و`--platform android` (يتطلب حساب Apple Developer وحساب Google Play Console).

### المزامنة الاختيارية (Supabase)

التطبيق يعمل كاملًا دون حساب. لتفعيل الحساب والمزامنة: أنشئ مشروع Supabase، طبّق `supabase/migrations/*.sql`، فعّل تسجيل الدخول برمز البريد (OTP)، ثم عرّف في بيئة البناء:

```
EXPO_PUBLIC_SUPABASE_URL=...
EXPO_PUBLIC_SUPABASE_ANON_KEY=...
```

## الخصوصية

لا إعلانات ولا أدوات تتبّع. الموقع يُستخدم على الجهاز فقط لحساب المواقيت والقبلة. البيانات محلية، ويمكن تصديرها أو حذفها من الإعدادات.
