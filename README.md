## ما الذي يقدّمه التطبيق

### 🕌 مواقيت الصلاة
- حساب فلكي دقيق **بدون إنترنت** — يعمل في أي مكان في العالم.
- ١٢ طريقة حساب معتمدة، وأم القرى هي الافتراضية.
- مذهب العصر: الجمهور أو الحنفي.
- الشروق والإمساك، وعدّاد تنازلي حيّ للصلاة القادمة.
- تعديل يدوي بالدقائق لكل صلاة لمطابقة تقويم مسجدك.
- حساب صحيح لأي مدينة حتى لو كنت في منطقة زمنية أخرى.

### 🔔 التنبيهات
- **تنبيه قبل الأذان بـ ٥ دقائق** (قابل للتغيير: ٥ / ١٠ / ١٥ / ٢٠ / ٣٠).
- تنبيه عند دخول وقت كل صلاة.
- تنبيه أذكار الصباح وأذكار المساء بوقت تختاره.
- تذكير الورد اليومي من القرآن.
- تنبيه السحور والإفطار في رمضان.

### 📿 الأذكار والأدعية
- **١٠ أبواب للأذكار**: الصباح، المساء، النوم، الاستيقاظ، الصلاة، بعد الصلاة، المسجد والأذان، المنزل والطعام، السفر، الهمّ والكرب.
- **١١ بابًا للأدعية**: من القرآن، من دعاء الرسول ﷺ، شاملة، مختصرة، الحمد والثناء، التسابيح، الاستغفار، الرقية بالقرآن، الرقية بالسنة، رمضان والعشر الأواخر، أدعية الميت.
- **كل نص موثّق بمصدره ودرجته** (البخاري، مسلم، أبو داود، الترمذي، النسائي، ابن ماجه، أحمد…) مع ذكر فضل الذكر إن ثبت.
- عدّاد لكل ذكر بعدد التكرار المشروع، ونسبة إنجاز اليوم، وحفظ في «أذكاري».
- أسماء الله الحسنى التسعة والتسعون مع معانيها.
- آداب الدعاء وأوقات الإجابة.

### 📖 الأحاديث
- **الأربعون النووية كاملة** (٤٢ حديثًا).
- منتخبات مرتّبة بالأبواب: الإيمان والتوحيد، الصلاة والطهارة، فضل القرآن، الصيام ورمضان، الذكر والدعاء، الأخلاق والمعاملة، الصدقة والإحسان، الرقائق والزهد.

### 📘 القرآن والختمة
- **خطة ختمة**: تختار عدد الأيام فيحسب لك التطبيق ورد كل يوم، وكم صفحة بقيت، وكم يومًا تبقّى، وهل أنت متقدّم أم متأخّر، والموعد المتوقّع لإتمام الختمة.
- خطط جاهزة: أسبوع، نصف شهر، شهر، شهران، ٣ أشهر، سنة — أو عدد أيام مخصّص.
- تسجيل الورد بضغطة، وتعديل الصفحة الحالية، وسجلّ الختمات السابقة.
- فهرس السور الـ١١٤ والأجزاء الـ٣٠، وقارئ مصحف بصفحات المدينة (٦٠٤ صفحات).
- تحميل الصفحات للقراءة **دون إنترنت**.

### 🧭 القبلة
- زاوية القبلة والمسافة إلى الكعبة بالحساب الفلكي.
- بوصلة حيّة تعمل بحسّاس الجهاز، وتخبرك كم تدير الجهاز يمينًا أو يسارًا.

### 🌙 شريط الصيام العلوي
- خط تقدّم يوضّح **كم بقي على الإفطار** وأنت صائم، و**كم بقي على الإمساك** وأنت مفطر.
- يعرض اليوم من رمضان، وكم بقي من الشهر، والتاريخ الهجري والميلادي واسم اليوم.
- **يظهر في رمضان تلقائيًّا ويختفي بانتهائه** — ويمكن جعله دائمًا أو إخفاؤه من الإعدادات.

### 📺 وغير ذلك
- بث مباشر من المسجد الحرام والمسجد النبوي، وإذاعتا القرآن الكريم والسنة.
- المسبحة الإلكترونية بأهداف (٣٣/٩٩/١٠٠/١٠٠٠) وأذكار جاهزة.
- **إحسان** — روابط مباشرة إلى المنصّات الرسمية للتبرّع (التطبيق لا يستقبل أي مبلغ ولا يأخذ عمولة).
- بحث شامل في كل النصوص.
- **الوضع الليلي والنهاري** (أو التلقائي حسب النظام)، وحجم خط قابل للتكبير.
- **تغيير أيقونة التطبيق** من الإعدادات (٦ أيقونات).
- نسخة احتياطية واستعادة لكل بياناتك.

## التشغيل

التطبيق **ويب تقدّمي (PWA)** بلا أي مكتبات خارجية ولا خطوة بناء — يكفي خادم ملفات ثابت:

```bash
git clone https://github.com/saadaljammaz35-stack/-.git
cd -
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

> ⚠️ لا تفتح `index.html` مباشرة من القرص (بروتوكول `file://`) لأن وحدات الجافاسكربت والعامل الخدمي لا تعمل إلا عبر خادم.

### التثبيت على الجوال
1. افتح رابط التطبيق في **Safari** (آيفون) أو **Chrome** (أندرويد).
2. من قائمة المشاركة اختر **«إضافة إلى الشاشة الرئيسية»**.
3. افتحه من الأيقونة، ثم فعّل التنبيهات من **الإعدادات ← التنبيهات**.

بعد التثبيت يعمل التطبيق كاملًا **دون إنترنت** عدا: صفحات المصحف غير المحمّلة مسبقًا، والبث المباشر.

### النشر على الويب
أي استضافة ملفات ثابتة تكفي — GitHub Pages أو Netlify أو Cloudflare Pages:

```bash
# GitHub Pages: Settings ← Pages ← Deploy from a branch ← اختر الفرع والمجلد الجذر
```

### النشر على App Store و Google Play
التطبيق مجهّز بـ **Capacitor** ليُبنى كتطبيق iOS و Android أصلي، مع **إشعارات مجدولة في نظام
التشغيل** تصل والتطبيق مغلق تمامًا:

```bash
npm install
npm run add:ios       # يحتاج جهاز Mac مع Xcode
npm run ios           # يفتح المشروع في Xcode
```

📄 **الخطوات كاملة في [`PUBLISHING.md`](PUBLISHING.md)** — المتطلبات، إعدادات Xcode، نصوص أذونات
`Info.plist`، بيانات المتجر جاهزة للنسخ، ولقطات الشاشة، وكيف تتفادى رفض المراجعة.

## الخصوصية

- **لا حساب ولا تسجيل دخول ولا تتبّع ولا إعلانات.**
- كل بياناتك (الختمة، المفضلة، الإعدادات، العدّاد) تُحفظ في متصفحك فقط ولا تُرسل لأي خادم.
- الموقع الجغرافي يُستخدم على الجهاز فقط لحساب المواقيت والقبلة.
- الاتصال بالإنترنت يُستخدم فقط لجلب صفحات المصحف والبث المباشر.
